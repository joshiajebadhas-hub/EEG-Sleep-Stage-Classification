# EEG-Based Sleep Stage Classification Using Random Forest

## Project Overview
This project focuses on classifying sleep stages from electroencephalogram (EEG) signals using a Random Forest machine learning model implemented in MATLAB.

## Objectives
- Process EEG signals from the Sleep-EDF dataset.
- Extract time-domain and frequency-domain features.
- Classify sleep into five stages: Wake, N1, N2, N3, and REM.
- Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.

## Technologies Used
- MATLAB
- Random Forest
- EEG signal processing
- Sleep-EDF dataset

## Methodology
1. Load EEG recordings and sleep-stage annotations.
2. Divide EEG signals into 30-second epochs.
3. Extract statistical features and frequency-band power.
4. Train and test a Random Forest classifier.
5. Evaluate classification performance using a confusion matrix and other metrics.

## Dataset
Sleep-EDF dataset. The original dataset files are not included in this repository. Obtain them from an authorized source and follow the applicable data-use terms.
